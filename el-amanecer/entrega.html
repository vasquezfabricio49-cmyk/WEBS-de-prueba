Publicación y reservas

Qué funciona hoy

La web pública, la carta completa, las fotos y los vídeos funcionan en GitHub Pages con el ordenador apagado. La carta es informativa: no hay carrito, pedidos ni pagos.

El panel permite editar platos, precios, descripciones, textos, fotografías, fuentes y portadas de vídeo. La edición y las pruebas de reservas se guardan en el navegador; todavía no existe una cuenta privada ni una agenda compartida entre dispositivos.

Publicar los cambios en GitHub

  1. Edita y guarda en el panel. «Ver mi web» muestra la vista local.
  2. Desde Resumen, descarga «Carta para GitHub» y «Textos y multimedia para GitHub».
  3. Sustituye el-amanecer/catalog.json y el-amanecer/site-content.json en la rama de publicación. Las fotos subidas desde el panel quedan incluidas en la configuración.
  4. Para vídeos nuevos, sube primero el archivo a el-amanecer/media/ y usa su dirección en el panel.
  5. Cuando GitHub termine de publicar, los visitantes verán el contenido nuevo. La configuración local del navegador puede seguir mostrando una versión propia.

Cómo deben funcionar las reservas reales

  1. El cliente rellena el formulario en el dominio del restaurante.
  2. Un servicio privado guarda la solicitud y la muestra en el panel del restaurante tras iniciar sesión.
  3. El restaurante acepta, rechaza o propone otra hora. Recibir una solicitud no confirma automáticamente una mesa.
  4. Al aceptar se envía la confirmación por el canal elegido; el panel registra si se entregó o falló.

Esto necesita base de datos compartida, acceso privado, almacenamiento de fotos y vídeos, servicio de correo y, si se elige, WhatsApp Business Platform. El formulario actual no hace ese envío automático ni guarda reservas en el panel de otro dispositivo. Un dominio por sí solo no incorpora estas funciones.

Preparación para activar el servicio

Recomendación: comenzar con correo electrónico y añadir WhatsApp si se necesita. Se requieren cuentas propiedad del restaurante, su correo y número de WhatsApp Business, acceso al dominio para verificar el remitente de correo y autorización para conectar el servicio de reservas. WhatsApp requiere alta del número y las plantillas aprobadas correspondientes. Las claves privadas se guardan en el servicio privado, nunca en los archivos públicos de GitHub.

La web puede permanecer en GitHub Pages y conservar el mismo dominio. La conexión de reservas sería un servicio adicional: no se ha usado ChatGPT Sites.
