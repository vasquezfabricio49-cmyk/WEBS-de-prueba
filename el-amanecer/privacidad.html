Tu solicitud y tus datos.

Esta publicación en GitHub Pages es una demostración. Utiliza datos ficticios para probar el formulario y el panel.

Solicitudes de prueba

El formulario guarda el nombre, teléfono, fecha, hora y número de personas únicamente en el almacenamiento local de este navegador. Estos datos no se suben a GitHub ni se envían al restaurante. Solo aparecen en el panel abierto en el mismo navegador, dispositivo y dirección de la web. Se eliminan al borrar los datos del sitio en el navegador. El panel demuestra la gestión, sin una agenda compartida ni una cuenta privada.

Contactar con el restaurante

Después de guardar la prueba puedes abrir un enlace de WhatsApp con un mensaje preparado. La solicitud solo llegará al restaurante si decides enviar ese mensaje en WhatsApp. No se envían comunicaciones automáticas y la disponibilidad debe confirmarla El Amanecer.

Cambios de la web y selección de platos

Las ediciones de textos, carta y fotos se guardan localmente en este navegador. No cambian la web de otros visitantes. El panel permite exportar una copia de la configuración y la carta. Las solicitudes de mesa no se incluyen en esas copias. La selección de platos permanece en memoria mientras la página está abierta, no crea pedidos ni realiza pagos.

Servicios externos

La web se aloja en GitHub Pages. El mapa incrustado carga contenido de Google Maps. Los botones de WhatsApp y llamada abren el servicio indicado cuando los seleccionas. Las fotografías del restaurante se presentan con fondo y luz ajustados.

Antes de una apertura comercial

El restaurante debe validar la carta, los precios, los alérgenos, los teléfonos y la disponibilidad. Una gestión real de reservas compartidas requiere almacenamiento central, acceso privado e información legal del responsable. Esta demostración local no ofrece esas funciones.
